04

功能一览

标的管理 → 现场报价 → 大屏投屏 → 成交归档，覆盖一场拍卖的主要环节。

控制台报价

应价 + 号牌双输入，触屏软键盘，报价规则自动校验。

副屏投屏

竞价页与欢迎页独立投屏，大字卡字号自动适配屏幕大小。

标的管理

Excel 模板批量导入导出，搜索分页，批量流拍 / 暂停 / 恢复。

成交归档与报表

成交瞬间锁定结果，《拍卖记录表》Excel 自动生成，签名区、分页都已排好。

公式引擎与配置

G4 公式引擎按自定义公式实时计算，参数列、参数名、公式都可配置。

桌面端工程化

桌面应用，数据存在本地；核心逻辑有自动化测试；三套主题，自动更新。

文件管理

系统内嵌文件管理器：按标的聚合浏览归档，图片/PDF 直接预览，下载或打包 zip，删除进回收站。

看每个功能的具体说明 →

06

关于这个项目

拍卖现场的传统流程里，报价靠喊、记录靠手写、大屏展示需要专人盯守、 散场后还要手工整理成交台账——每个环节都依赖现场人员的专注与经验， 在紧张节奏下容易出错，事后也难以追溯。这套系统把 「标的管理 → 现场报价 → 大屏投屏 → 成交归档」的完整流程结构化、标准化：每个环节都有明确的规则， 每一步操作都有可追溯的记录，让一场拍卖从头到尾清晰可控。

系统由我个人维护，不追求大而全， 只把该做好的内容结构化、标准化，并把每一步改进做扎实。 核心逻辑对齐行业里成熟的桌面版流程，写有自动化测试； 如果你在实际使用中发现什么问题，欢迎在GitHub上提 issue。
