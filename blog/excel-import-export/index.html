Excel 导入导出与模板闭环

August 28, 2026

Excel 导入导出是标的管理的高频路径，实现位于 src/utils/excel.js。设计目标：模板可下载、导入不出错、导出能回导。

13 列模板

模板对齐标的管理表头：标的名称 / 欢迎页 PDF / 欢迎页图片目录 / 展示标题 / 标的图片 1-6 / 金额单位 / 起拍价 / 拍卖方式，共 13 列。导出使用同一模板格式（buildExportAoa），导出的文件可直接再次导入，形成闭环。

按列名映射，兼容历史版本

parseImport 不做固定列序的刚性解析，而是按列名模糊匹配：

const headers = rows[headerIdx].map(normHeader);          // 表头标准化
const colOf = (...keys) => headers.findIndex((h) =>
  keys.some((k) => h && h.includes(normHeader(k))));      // 列名模糊匹配

历史版本的模板列名略有差异也能匹配到正确列。

原子替换 + 回滚

批量导入采用原子替换：解析并构建全部标的成功后一次性 REPLACE_TARGETS；任一行解析失败则恢复导入前的 prev 快照，要么全部成功、要么整体回滚。

无幅度列继承默认

导入模板没有竞价幅度列时（历史模板常见），导入标的的幅度继承当前激活标的的竞价幅度，而不是归零——避免导入后无法正常加价（有回归用例锁定）。

报表导出

  • 汇总报表表头：标的 / 成交价 / 领先号牌 / 生成时间 / 结果，支持单标的导出与全局一键导出；
  • 成交报表含抬头信息块（标的名称 / 序号 / 展示标题 / 起拍价 / 竞价幅度 / 拍卖方式 / 成交价 / 领先号牌 / 金额单位 / 生成时间）+ 报价分栏表（45 轮 / 页、多页分页、买受人签名区），可直接对外交付。
