项目架构与技术栈

React 18 + Vite 5 + Electron 33 + sql.js 的三层架构：渲染进程、主进程与数据层的职责划分，双入口构建与多宿主兼容。

架构技术栈

Electron 架构：主进程权威态与多窗口管理

主进程权威态、集中式 IPC 中转、配置即时通道、投屏窗崩溃自动恢复，以及 sql.js 纯 WASM 数据库与三宿主兼容的设计。

架构Electron

状态管理与跨窗口数据流

Context + useReducer 全局状态：300ms 防抖落盘、config 50ms 即时通道、投屏窗只读订阅、normalizeState 兼容迁移与主进程权威态的单向数据流。

标的数据模型与持久化

标的字段分组、报价记录结构、删除撤销栈与重开快照，以及 sql.js 四表的增量 upsert、prune 兜底与首次启动迁移。
