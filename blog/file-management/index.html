文件管理 Tab · 需求方案

August 29, 2026

成交报表、现场截图、欢迎页媒体，都会自动归档到系统目录。但归档之后的日常管理——核对、导出、清理——过去要人工打开系统文件管理器，逐层翻找。这份方案把文件管理收进系统内。

设计原则

  • 以标的为中心：同一标的的欢迎页媒体、竞价页图片、成交归档聚合在一起，不跨目录翻找
  • 不改变物理归档结构：逻辑/类型视图都是对现有目录的不同呈现，存量兼容、零迁移
  • 与系统文件管理器一致的操作体验：双击预览、右键菜单、多选、回收站删除
  • 导入即设置：逻辑视图各分组提供「导入」按钮，导入后可选设为标的对应字段（文件管理器也能设置标的）

两种视图

视图说明
逻辑视图（默认）按标的聚合：每个标的分组完整显示「欢迎页 PDF / 欢迎页图片 / 竞价页图片 / 成交报表 / 成交截图」，每组带「导入」按钮；外部改动自动同步刷新
类型视图（下拉筛选）下拉即筛选器：全部文件（PDF/图片/报表/成交截图全可见）/ 全部图片 / 全部 PDF / 全部成交报表 / 全部成交截图，按时间倒序全局巡检

核心功能

  • 分组导入 → 设为标的字段：每个分组「导入」选文件复制到对应归档目录，导入后可选设为标的——欢迎页 PDF→标的 welcomePdf、欢迎页图片→标的 welcomeImages、竞价页图片→标的 media（标的图片，竞价页展示）；报表/截图仅落盘
  • 预览：图片内嵌缩放与同组切换；PDF 复用投屏渲染引擎（按钮/滚动翻页、Ctrl+滚轮缩放、双击缩放、官方 pdf.js viewer 渲染）；Excel/文本下载打开
  • 下载 / 导出：单个文件保存对话框导出；多选 zip 打包下载
  • 删除：移入系统回收站（可恢复），媒体列表同步移除该文件；数据库文件只读保护
  • 外部变更自动同步：系统资源管理器改动归档文件，文件管理自动刷新（fs.watch 监听）
  • 归档相对路径：文件行/预览弹窗显示归档内相对路径（如 欢迎页/标的A/pdf/xx.pdf），不暴露本机绝对路径
  • 系统资源管理器入口：工具栏「打开位置」直接打开归档根/定位文件

媒体映射（V1.8 修正）

业务字段语义落盘目录
welcomePdf欢迎页 PDF（欢迎页投屏展示）欢迎页/{标的}/pdf
welcomeImages欢迎页图片（欢迎页轮播）欢迎页/{标的}/图片
media（标的图片）竞价页展示图片竞价页/{标的}/图片

修正说明：标的图片与欢迎页图片语义独立——标的图片一律落 竞价页/{标的}/图片，欢迎页选图不再自动并入标的媒体（此前映射混同）。

与其他上传 / 媒体入口的职责边界

系统里有多个"放文件"的入口：控制台的欢迎页区、标的详情的媒体 tab、系统设置（系统背景），加上文件管理——容易互相打架。设计上按业务层与文件层分离 + 可选联动化解：

入口职责是否改业务字段
控制台 · 欢迎页区绑定欢迎页 PDF / 图片（业务操作）是
标的详情 · 媒体 tab管理标的媒体（业务操作）是
文件管理 Tab归档文件运维 + 分组导入可设为标的字段可选（导入后确认）
系统设置系统背景等全局素材（配置域）是（全局字段）

联动规则：

  • 导入：文件管理分组导入复制到归档目录；导入后弹确认「设为标的的 XX？」——确认则写入标的对应业务字段（欢迎页 PDF/欢迎页图片/标的图片）
  • 删除：文件管理回收站删除被业务引用的文件时，媒体列表同步移除该引用（无状态残留）
  • 关联标注：逻辑视图中被业务引用的文件带标记（"欢迎页"/"标的图片"），删除前提示影响范围
  • 边界：系统背景等全局素材归系统设置，不与归档文件混同

这样每个入口职责清晰：业务字段可由业务入口或文件管理导入设置，文件管理只管文件，删除有明确联动，不会出现"上传了却不知道影响哪里"的混乱。

实现状态

  1. ✅ 第一迭代（闭环）已上线：逻辑视图（按标的聚合）+ 预览 + 下载/zip 打包 + 回收站删除（媒体同步移除）+ 搜索刷新 + 系统资源管理器入口
  2. ✅ 第二迭代已上线：类型视图下拉筛选（全部文件（含 PDF/图片/报表/截图）/全部图片/全部 PDF/报表/截图）+ 逻辑视图完整展示 + 文件重命名 + 右键菜单
  3. ✅ V1.8 导入设置标的 + 媒体映射修正：逻辑视图分组导入（5 组恒显 + 导入按钮）+ 可选设为标的字段；标的图片落 竞价页/{标的}/图片（kind=mainpage）、欢迎页选图不再并入标的媒体；物理视图按用户决定隐藏（代码保留）；归档外部变更自动同步（fs.watch）；归档相对路径显示；删除标的物理文件彻底清理（3 根级目录 + 回收站 + 校验）
  4. ✅ 关联修复：PDF 官方 viewer 迁移（容器 absolute / setDocument 传对象 / 自算 fit 缩放基准修正）、投屏持久化异步化（push-state 500ms 防抖 + 退出 flush）、投屏 PDF 翻页/缩放即时通道、标的详情单页
