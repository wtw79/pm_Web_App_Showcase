G4 公式引擎：参数列实时计算

August 28, 2026

土地 / 房产拍卖现场需要展示单位地价、楼面地价、溢价率等派生指标。竞价页的 Cn4-Cn7 参数列由公式实时计算，位于 src/logic/formula.ts。

变量约定

  • DD：总价（当前应价 / 成交价）
  • C1 ~ C4：标的常量参数（在标的详情页录入，参数名称在系统设置中自定义）

默认公式配置：

列默认公式含义
Cn4DD/C1单位地价
Cn5DD/C2楼面地价
Cn6DD/(C1*C2)派生指标
Cn7（空）不计算，结果为 0

求值流程

变量代入（DD/C1-C4 → 数值）
  → tokenize 分词（数字 / 运算符 / 括号，支持负号）
  → toPostfix 中缀转后缀（Shunting-yard 调度场算法）
  → evalPostfix 后缀求值

运算符优先级：/ > * > - > +，支持任意层括号。

容错语义

变量为空、除零、语法错误等异常路径统一返回 0。求值错误不中断渲染——大屏展示场景下保证页面持续可用。

配置入口

系统设置中可编辑：Cn1-Cn3 为固定列（显示标的静态信息），Cn4-Cn7 的标题与公式均可配置，例如溢价率 (DD-C3)/C3*100。
