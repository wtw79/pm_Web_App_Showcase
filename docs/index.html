📖 项目简介

拍卖会现场管理系统，提供从标的建档、实时报价、领先计算、成交确认、自动归档到副屏投屏展示的完整业务闭环。本项目是 pm（WPF 桌面端）的 Web/Electron 移植实现，业务逻辑严格对齐 pm，可作为独立产品运行。

✨ 核心特性

面向拍卖现场的高频交互场景设计，所有功能均已通过 88 个自动化测试用例覆盖。

标的管理

批量新增 / 导入导出（Excel 13 列模板，可回导）/ 搜索分页 / 批量操作（删除/流拍/暂停/恢复/清空）

实时报价

应价 + 号牌双输入 · 内嵌软键盘（快速/默认双模式）· 报价校验（增价不低于起拍价 / 减价不高于）

🏗 架构说明

单生产者模型：控制台是唯一状态生产者（持久化+广播），投屏窗只读，杜绝双窗口回环。主进程经 IPC 中转持久化（SQLite）与广播。

┌─────────────────┐  pushState / RELOAD   ┌──────────────────┐
│  控制台窗口      ─────────────────────►  │  主进程(IPC)      │
│ (persist=true)  ◄─────────────────────  │  ipc-hub.cjs    │
└─────────────────┘   broadcastToDisplays  └────────┬─────────┘
                                                  │ 状态落 SQL(sql.js) + 广播
                                     ┌────────────▼────────┐
                                     │   投屏窗(只读)      │
                                     │  bigscreen.html    │
                                     └─────────────────────┘

─ 状态迁移兼容 ─
normalizeState(s)  →  旧数据自动升级
  · 标题 8 字段 → 4 字段（欢迎/竞价共用）
  · 背景多形态 → 系统级单一
  · 删除当前标的 → activeId=null（不回退第一个）
