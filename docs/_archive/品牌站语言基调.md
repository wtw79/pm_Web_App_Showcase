# 品牌站语言基调

> 一句话：**像一个在拍卖现场待过的人，低声向路过的人介绍他熟悉的东西——不推销，只陈述，但陈述里有画面。**
> 这份文档本身也按这个基调写。生成日期：2026-08-30

---

## 1. 它怎么说话

**三件事：具体、克制、在场。**

**具体**——说得出画面，不说得出概念。

- 说："报价靠喊、记录靠笔、校验靠心算，越到关键轮次越容易出错。"
- 不说："传统流程效率低下，亟需数字化升级。"
- 说："落槌的瞬间，成交记录、报表、现场截图已经躺进这个标的的文件夹里。"
- 不说："一键式智能化成交归档解决方案。"

**克制**——不夸张、不堆砌、不喧哗。

- 不出现"最、第一、领先、唯一、革命性"。
- 不出现"高效、强大、专业、智能、先进、一站式、赋能"。
- 不感叹，不煽情。允许的修辞只有朴素的比喻与画面。
- 一个数字能说明白的事，不用两个数字；一个词能说清的事，不用一个短语。

**在场**——站在拍卖现场这个房间里说话，不站在云端俯瞰。

- 用现场的词：起拍、应价、号牌、领先、落槌、流拍、归档、大屏、散场。
- 跟随现场的节奏：起拍 → 应价 → 落槌 → 归档。
- 称呼它，用"它"——一具被看见的身体。不说"本产品""我司系统"。
  - 说："它从 2021 年活到今天。"
  - 不说："本系统采用先进技术…"

## 2. 它不说内脏

观众看见的是身体，不是解剖台上的内脏。测试、技术栈、内部通道、安装与更新的工程手段——这些是手术室里的事，观众不看。

**主叙事里不出现：**
- 测试的数量、分层、体系
- 技术栈的名字与版本
- 错误码、内部通道、日志、防抖这些看不见的东西
- 安装包、自动更新、托盘这类工程手段

**观众看得见的，保留：**
- 三套主题——它有三身衣服，随现场换
- 两块屏幕——一块操作，一块展示
- 大屏上的字、领先的号牌、45 轮一页的《拍卖记录表》
- 导入导出、搜索、批量操作——它替人干的活
- 文件管理——归档收进它自己肚子里
- 公式引擎——它替人按计算器
- 它待在哪儿：艺术品、资产房产、二手车、典当司法

**有些事换成性格的话来说：**
- 断网也能跑完一场拍卖 → 它不赌运气，靠得住
- 每步都能撤回 → 手滑了，它给你反悔的机会
- 数据只在本机 → 你的东西只躺在你电脑里，它不带走
- 2021 年改到现在 → 它从 2021 年活到今天，改过很多次

**数字只留现场能看见的：** 三套主题、两块屏幕、45 轮一页、V2.3.00、2021 年至今。
**其余数字（测试数、性能、次数）不进主叙事。**

**唯一的内脏容身处**是文档中心——想看构造的人自己走进去。入口保持轻盈，不喧宾夺主。

## 3. 发布前自检

- [ ] 它像介绍一个存在，不像推销一个产品？
- [ ] 有没有"最/第一/高效/强大/智能/一站式/赋能"？有就删
- [ ] 有没有测试数字、技术栈名字、内部术语？有就删或移文档中心
- [ ] 句子里有画面吗？
- [ ] 删掉任何一个数字、形容词后句子还成立吗？成立就删
- [ ] 不懂拍卖、不懂技术的人读得懂吗？

## 附录 A · 执行对照清单（工具，不是文案）

> 这份清单丑，因为它只是给动手改站的人对照用的工具；它本身不允许出现在站点文案里。

**主叙事删除（对应 §2 第一段）：** 测试数量与体系（含 88、119、L1-L4 这类）、技术栈名（React、Vite、Electron、sql.js、SheetJS、pdfjs、Vitest 等）、traceId、错误码编号、IPC、持久化防抖、fs.watch、NSIS、自动更新、托盘、多宿主、单生产者模型、主进程权威态、normalizeState。
**主叙事保留（对应 §2 第二段）：** 三主题、双屏投屏、大字卡、领先高亮、45 轮/页报表与签名区、Excel 导入导出、搜索分页、批量操作、文件管理（聚合/预览/回收站）、公式引擎、四类现场。
**转为性格（对应 §2 第三段）：** 断网可用、出错可逆、数据本地、2021 至今。
**数字口径：** 主叙事只允许 3 主题 / 2 屏 / 45 轮 / V2.3.00 / 2021 年；文档中心不受限。
