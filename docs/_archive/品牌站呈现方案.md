## 0. 一句话立场

品牌站是这具系统的**身体**，让它可以被看见。因此，品牌站的每一处呈现，都服务于一个动词：**看见**。

## 1. 呈现原则（五条，承自理念解析 §5）

1. **呈现，而非说服**——展示系统是什么，不推销它为什么好。
2. **展示存在，而非堆功能**——先让人看见"它是个什么样的存在"，功能是它的动作。
3. **尊重边界，而非拉近转化**——不设"得到"的入口；演示是"隔窗看它工作"。
4. **身体必须真实**——界面、数字、边界与真实系统一致；不夸大、不编造、不美化。
5. **让系统自己说话**——界面、动作、历史就是它的语言，文案是低声旁白。

## 2. 品牌站要呈现的"五个看见"（方向性内容结构）

品牌站整体围绕"身体"的五重展开来组织内容：

| 看见什么 | 对应内容 | 落点 |
|---|---|---|
| 形态——它长什么样 | 真实界面（控制台三主题）、大屏投屏效果、报表/文件管理真实样子 | 首页主视觉、产品功能 |
| 动作——它怎么工作 | 起拍 → 应价 → 落槌 → 归档的完整流程 | 在线演示（核心）、首页引导 |
| 性格——它是什么性格 | 严谨（规则校验/成交锁定）、可逆（每步可撤回）、克制（只做现场该做的）、诚实（一个人维护）、离线可靠 | 首页叙述、页脚、各页气质 |
| 生命——它怎么活到今天 | 2021 → 2026 的版本成长史，每个版本的呼吸 | 版本发布 |
| 构造——它由什么构成 | 架构、状态机、公式引擎、数据模型、测试体系 | 文档中心 |

## 3. 页面方向（七页，各自承担一个"看见"）

| 页面 | 它承担什么 | 方向要点 |
|---|---|---|
| 首页 | 第一眼看见它 | 形态先行：真实大屏/界面为主视觉，配一句"它是这样的存在"；动作与性格次第展开；入口只有"看它工作""看它的构造"。**无技术栈、无测试数字** |
| 产品功能 | 细看它的部位 | 七个模块按真实使用流程呈现，每个模块用真实截图 + 它在现场解决了什么（不说"为什么买"，不列技术手段） |
| 适用场景 | 它适合待在哪 | 四种现场（艺术品文物/资产房产/二手车物资/典当司法），呈现"这种场合它如何运转" |
| 在线演示 | 隔窗看它工作 | 核心页。完整流程可走通；明确"这里看到的是它在浏览器里的样子"，桌面版能力边界诚实标注 |
| 文档中心 | 看它的构造 | 架构、状态机、公式引擎等解剖内容——**唯一的"内脏"容身处**，入口保持轻盈 |
| 版本发布 | 看它怎么活到今天 | 成长史时间线（用现场语言叙述，不列工程手段清单）；版本 V2.3.00 |
| 联系 | 与作者聊聊 | 纯对话：GitHub issue / 邮箱；无商业入口；权益声明诚实呈现 |

> 导航骨架（首页/产品功能/适用场景/在线演示/文档中心/版本发布/联系）经此定位审视，**方向成立**，无需推翻。
> /projects、/resume 两个影子页面与 /features、/updates 内容重复——是否删除属执行决策，方向上建议合并，待确认。

## 4. 内容基调（方向级）

- **语言基调：现场旁白**——像一个在拍卖现场待过的人，低声向路过的人介绍他熟悉的东西；不推销，只陈述，但陈述里有画面。完整定义与例句对照见 `品牌站语言基调.md`。
- **剥离工程内脏**：测试、技术栈、内部通道、安装与更新的工程手段——主叙事一概不出现，只有"现场可感知"的东西被呈现（三套主题、两块屏幕、45 轮一页、2021 年至今）。完整准则见 `品牌站语言基调.md`。
- **关于"一个人维护"**：这不是弱点需要遮掩，而是这具身体的**性格**——诚实呈现。
- **能力边界**：演示版 ≠ 桌面版；展示站不含源代码与可执行程序——边界即诚实，诚实即尊重。

## 5. 关于真实素材（方向）

- 品牌站主视觉应使用**真实系统界面**（V2.3.00），而非示意图或模板图。
- 现有截图多为 V2.2.0 旧版且缺文件管理界面，需要重截——这属于执行阶段事务，方向已定：**真实形态优先**。
