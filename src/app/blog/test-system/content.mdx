## 关键回归用例

- **报表「轮次残留领先」**：历史数据 `d1` 字段残留导致后续轮次仍显示领先。修复为渲染时按规则重算状态，并加入回归用例锁定。
- **模板无幅度列继承默认**：Excel 导入模板没有竞价幅度列时，导入标的幅度继承当前激活标的的竞价幅度，而不是归零导致无法加价。
- **删除当前标的回未选态**：删除正在使用的标的时 `activeId` 回退为 `null`（保持"未选择"），而不是自动选中第一个。

## 运行方式

```bash
npm test          # 全部用例
npm run test:watch  # 监听模式
```

用例与 `src/logic/`、`src/models/`、`src/utils/` 保持纯函数依赖，运行在 Node 环境，不依赖 UI。
