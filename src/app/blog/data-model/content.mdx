一个标的由 `models/target.ts` 的 `createTarget()` 工厂创建，字段按职责分组：

```ts
{
  // 标识与竞价参数
  id, name, lotNo,
  qiPaiJinEr,          // 起拍价
  qiPaiZengJiaJinEr,   // 竞价幅度
  jinErDanWei,         // 金额单位
  auctionMode,         // 1 增价 / -1 减价

  // 运行态
  haoPai, jinEr,       // 当前领先号牌 / 价格
  roundCounter,        // 轮次计数
  isBeginPaiMai, isPaused, isClosed, closeReason,
  dealPrice, dealPlate, dealAt,   // 成交字段

  // 报价记录
  records: [],         // 最新在前，records[0] 为当前领先
  deletedRows: [],     // 删除任意行撤销栈
  restartSnapshot,     // 重新开始快照

  // 展示 / 媒体 / 公式参数 / 键盘
  showTitle, biaoDiInfo,
  media, welcomePdf, welcomeImages,
  c1..c4, keyboard, createdAt,
}
```

## 报价记录结构

每条报价 `{ round, d1, d2, d3, d4..d8 }`：`d1` 状态（领先/出局/成交）、`d2` 号牌、`d3` 金额、`d4..d8` 自定义参数列。数组**最新在前**，新报价 `unshift` 到头部，旧领先自动转出局。

## 可逆操作的数据支撑

- **deletedRows 撤销栈**：`deleteBid` 删除任意行时压入 `{ record, index }`，`undoDeleteBid` 按原位置精确还原（含领先状态）；
- **restartSnapshot 快照**：`restart` 清空前保存 `records + roundCounter`，`restoreRestart` 一键恢复。

## 持久化：sql.js 四表

| 表 | 内容 |
|----|------|
| `kv` | config / projection / projCtl / meta 键值 |
| `targets` | 标的（data 字段存完整 JSON，增量 upsert） |
| `media` | 媒体台账（关联 target_id） |
| `deal_artifacts` | 成交归档台账（report / screenshot） |

关键机制：**增量 upsert**（按 id `INSERT OR REPLACE`，避免全表重写）+ **pruneTargets 兜底清理孤儿行**；sql.js 不自动持久化，需手动 `flush()`（内存库 `export()` 写文件）；首次启动自动迁移旧 `auction-state.json` → 改名 `.migrated` 归档。文件层面按 `AuctionData/数据/{标的名}/`、`欢迎页/`、`竞价页/` 目录树归档媒体与报表。
