标的由 `src/models/target.ts` 的 `createTarget()` 工厂创建，字段按职责分组：

```ts
{
  // 标识与竞价参数
  id, name, lotNo,
  qiPaiJinEr,          // 起拍价
  qiPaiZengJiaJinEr,   // 竞价幅度
  jinErDanWei,         // 金额单位
  auctionMode,         // 1 增价 / -1 减价

  records: [],         // 最新在前，records[0] 为当前领先
  deletedRows: [],     // 删除任意行的撤销栈
  restartSnapshot,     // 重新开始快照

  // 展示 / 媒体 / 公式参数 / 键盘
  showTitle, biaoDiInfo,
  media, welcomePdf, welcomeImages,
  c1..c4, keyboard, createdAt,

```

## 可逆操作的数据支撑

- **deletedRows 撤销栈**：删除任意行时压入 `{ record, index }`，撤销时按原位置还原（含领先状态）；
- **restartSnapshot 快照**：重新开始时保存 `records + roundCounter`，可一键恢复。

## 持久化：sql.js 四表

| 表 | 内容 |
|----|------|
| `kv` | config / projection / projCtl / meta 键值 |
| `targets` | 标的（data 字段存完整 JSON） |
| `media` | 媒体台账（关联 target_id） |
| `deal_artifacts` | 成交归档台账（report / screenshot） |

机制要点：

- **增量 upsert**：按 id `INSERT OR REPLACE`，避免全表重写；
- **prune 兜底**：清理孤儿行；
- **手动 flush**：sql.js 不自动持久化，内存库通过 `export()` 写文件；
- **首次启动迁移**：旧 `auction-state.json` 自动迁移后改名 `.migrated` 归档；
- **文件目录树**：按 `AuctionData/数据/{标的名}/`、`欢迎页/`、`竞价页/` 归档媒体与报表。
