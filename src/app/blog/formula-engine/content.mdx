土地 / 房产拍卖现场，观众不仅看价格，还要看**单位地价、楼面地价、溢价率**等派生指标。竞价页的 Cn4-Cn7 参数列由公式实时计算，报价一跳即算即显。

## 变量约定

- `DD`：总价（当前应价 / 成交价）
- `C1` ~ `C4`：标的常量参数（按标的在详情页录入）

默认公式配置：

| 列 | 默认公式 | 含义 |
|----|----------|------|
| Cn4 | `DD/C1` | 单位地价 |
| Cn5 | `DD/C2` | 楼面地价 |
| Cn6 | `DD/(C1*C2)` | 溢价相关指标 |
| Cn7 | （空） | 不计算，结果 0 |

## 求值流程

```text
变量代入（DD/C1-C4 → 数值）
  → tokenize 分词（数字 / 运算符 / 括号，支持负号）
  → toPostfix 中缀转后缀（Shunting-yard 调度场算法）
  → evalPostfix 后缀求值
```

运算符优先级严格：`/`(4) > `*`(3) > `-`(2) > `+`(1)。

## 容错语义：错误一律归零

变量为空、除零、语法错误——所有异常路径统一返回 `0`。这是刻意的设计：大屏展示场景下，**宁可显示 0 也不能让求值异常中断渲染**。现场没有重启系统的机会。

配置入口在系统设置：Cn1-Cn3 为固定列（显示标的静态信息），Cn4-Cn7 标题与公式均可编辑，如溢价率 `(DD-C3)/C3*100`。
