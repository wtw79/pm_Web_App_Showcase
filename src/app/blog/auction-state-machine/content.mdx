竞价逻辑位于 `src/logic/auction.ts`，一个标的的生命周期状态迁移如下：

```text
未开始 → 进行中 → 暂停（可恢复）
                → 已成交（isClosed + 成交）
                → 流拍（isClosed + 流拍）
```

## 报价记录与三态

每条报价记录 `{ round, d1, d2, d3, d4..d8 }`：

- `d1`：状态（领先 / 出局 / 成交）
- `d2`：号牌
- `d3`：金额
- `d4..d8`：自定义参数列

`records` 数组**最新在前**，`records[0]` 为当前领先。三种状态：

| 状态 | 含义 |
|------|------|
| 领先 | 当前最高价（进行中，多笔同价并列均领先） |
| 出局 | 被更高价超越 |
| 成交 | 确认成交后锁定唯一一笔 |

渲染报表 / 控制台时按规则**重算**每条记录状态（不信任持久化的 `d1` 字段），保证历史数据展示一致。

## 操作与校验

- **报价校验**：号牌纯数字、价格有效、增价不低于起拍价、减价不高于起拍价；
- **撤回上一手**：`records.shift()`，次席自动晋升领先；
- **删除任意行可撤销**：删除时压入 `deletedRows` 撤销栈 `{ record, index }`，可按原位置精确还原；
- **重新开始带快照**：清空前保存 `restartSnapshot`（records + roundCounter），可恢复；
- **成交前二次校验**：确认成交时再次执行价格规则复核，非法数据不进入归档。

## 增价与减价

`auctionMode = 1` 为增价（每手至少加一个幅度），`-1` 为减价（荷兰式，每手往下减）。校验方向、下一手建议价计算（`基准 + 幅度 × 方向`）、大屏"增价幅度 / 减价幅度"标签均随模式切换。
