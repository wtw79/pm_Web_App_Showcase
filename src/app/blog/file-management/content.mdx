成交报表、现场截图、欢迎页媒体，都会自动归档到系统目录。但归档之后的日常管理——核对、导出、清理——过去要人工打开系统文件管理器，逐层翻找。这份方案把文件管理收进系统内。

## 设计原则

- **以标的为中心**：同一标的的欢迎页媒体、竞价页图片、成交归档聚合在一起，不跨目录翻找
- **不改变物理归档结构**：三种视图都是对现有目录的不同呈现，存量兼容、零迁移
- **与系统文件管理器一致的操作体验**：双击预览、右键菜单、多选、拖拽、回收站删除

## 三种视图

| 视图 | 说明 |
|------|------|
| **逻辑视图（默认）** | 按标的聚合：每个标的分组显示「欢迎页 / 竞价页图片 / 成交归档」，文件缩略图直览 |
| **物理视图** | 原始目录树（`AuctionData/欢迎页|竞价页|数据`），供高级整理：新建、重命名、移动、复制 |
| **类型视图** | 下拉切换：全部媒体 / 全部成交报表 / 全部成交截图，按时间倒序全局巡检 |

## 核心功能

- **预览**：图片内嵌缩放与同组切换；PDF 复用投屏渲染引擎；Excel/文本下载打开
- **下载 / 导出**：单个文件保存对话框导出；多选 **zip 打包下载**
- **删除**：移入**系统回收站**（可恢复），媒体列表同步移除该文件；数据库文件只读保护
- **上传导入**：文件/目录复制到目标目录，属于标的目录时写媒体台账
- **系统资源管理器入口**：在文件管理内直接打开/定位归档目录
- **搜索 / 刷新 / 排序**：三种视图均支持

## 安全与一致性

- 访问白名单仅限归档根（`AuctionData`），主进程校验路径，拒绝越界
- 删除/覆盖/移动需确认；数据库文件与使用中文件受保护
- 文件操作同步媒体台账，标的目录重命名默认禁止（防止引用失效）

## 实现节奏

1. **第一迭代（闭环）**：逻辑视图 + 预览 + 下载/zip + 回收站删除 + 搜索刷新 + 系统定位入口
2. **第二迭代**：类型视图（下拉）+ 物理视图整理（重命名/新建/移动/复制）+ 右键菜单
3. **择机**：回收站内还原入口、预览面板、拖拽增强
