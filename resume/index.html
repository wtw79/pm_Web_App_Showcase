版本演进

2026

V2.3.00

文件管理 Tab 上线

归档管理收进系统内：按标的聚合浏览、预览、下载、回收站删除，不再依赖人工开文件管理器

文件管理顶级 Tab：逻辑视图（按标的聚合：欢迎页 PDF/图片、竞价页图片、成交报表/截图）+ 类型视图（下拉：全部媒体（含 PDF）/报表/截图）

系统内文件操作：图片/PDF 内嵌预览、下载导出、多选 zip 打包、删除进系统回收站（媒体列表同步移除）

逻辑视图「PDF / 图片 / 报表 / 截图」类别筛选：默认全开，媒体与 PDF 可分别筛选，界面聚焦

文件重命名 + 右键菜单（预览/下载/重命名/删除/系统定位）

系统资源管理器入口：在文件管理内直接打开/定位归档目录

标的详情单开一页：独立路由浏览详情，返回一键回标的管理

投屏 PDF 渲染兼容修复：pdfjs 降级至自带 toHex 兼容的稳定版，旧内核宿主也能正常渲染

软键盘与报价体验：键盘设置只生成数字键、报价键盘固定默认布局、点击外部稳定收起

2026

2026 · Web / Electron 重构版

从 WPF 到 Web 技术栈重构

React 18 + Vite 5 + Electron 33 全新实现，业务逻辑对齐桌面版，浏览器可直接运行

三主题换肤升级（Aurora 青绿 / Obsidian 深空 / Glass 玻璃），控制台与投屏全套统一

软键盘重构为自适应页面浮窗：尺寸随内容、锚定触发输入框，牌号键盘 digitsOnly 快速报价

成交归档增强：一键完成报表 + 现场截图 + 按标的归档，截图失败自动降级 canvas 快照

报表改为「保存 pm 模板 + 填充」：45 轮/页、买受人签名区，可直接对外交付

投屏媒体渲染加固：消除裂图闪烁、失败可见、PDF 渲染资源（CMap/标准字体/wasm）配置修复

成交弹窗修复（ARGB→CSS alpha 顺序）与红色半透明 UI 升级
