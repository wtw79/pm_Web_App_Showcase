控制台报价

ReactReact Context

一场拍卖的核心操作区：投屏状态条、起拍设置（增/减价）、竞价区（应价+号牌输入即提交）、操作面板（成交/流拍/撤回/撤销删除/暂停/重开）与实时报价记录表。

投屏状态条：副屏 1「竞价页」与副屏 2「欢迎页」的投屏中 / 未投屏 状态一目了然；一键投屏竞价页 / 欢迎页、选择投放屏幕、打开投屏信息面板 （实时预览截图）、切换主题。

欢迎页管理：PDF 播放（加载 PDF、上一页 / 下一页、页码跳转、 放大缩小、全屏）与图片轮播（选择图片目录、自动间隔、手动翻页）；标的控制以自动间隔 + 翻页 / 缩放 / 全屏远程驱动投屏页。

起拍设置：起拍价（按金额单位显示）、竞价幅度、金额单位切换、 拍卖方式增价 / 减价（开始后不可更改）。

竞价区：应价 + 号牌双输入，回车可直接跳转提交；支持内嵌 软键盘与自定义参数列，公式列（G4）实时自动计算；报价通过输入即提交缩短操作路径，配合防重复签名避免同一手被并发提交。

操作面板：确认成交、流拍、删除上条、撤销删除、暂停 / 恢复继续、 重新开始（快照可恢复）、导出数据、查看报表、刷新表格；报价记录表实时显示 轮次 / 号牌 / 应价与领先 / 出局 / 成交状态高亮，支持行级删除。 成交前进行二次校验，非法数据无法进入归档。
