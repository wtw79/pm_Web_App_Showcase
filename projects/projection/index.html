副屏投屏

Electronpdfjs-dist

欢迎页（PDF / 图片轮播）与竞价页（2×2 大字卡 + 实时报价表）独立投放到不同物理显示器；Viewbox Uniform 等比缩放无黑边，投屏窗崩溃自动恢复。

双屏并行展示：主屏操作、副屏展示的经典拍卖现场布局——竞价页投副屏 1， 欢迎页投副屏 2，互不干扰；系统自动枚举所有物理显示器，可指定投放目标并做 DPI 自适应。

欢迎页：主 / 副标题居中 + 日期；PDF 公告使用 pdfjs 在 canvas 上纯净渲染（翻页 / 缩放 / 全屏 / 页码跳转），避免浏览器内置 PDF 查看器 的下载 / 打印工具栏；也支持图片轮播（自动间隔）。

竞价页：顶栏标题；中部左侧为竞价标的信息与图片、右侧为 2×2 大字卡 （起拍价 / 当前号牌 / 增价幅度 / 最新应价，字号按窗体文字大小 × 不同系数）； 底部为实时报价表，领先 / 成交行高亮。画面按Viewbox Uniform 等比缩放，任何分辨率下比例一致、无黑边。

投屏可靠性：投屏窗无边框置顶全屏，所有翻页 / 缩放 / 全屏由控制台 远程驱动（无控制条防误触）；渲染进程崩溃自动重启（最多 3 次），连续崩溃 通知控制台；投屏信息面板实时预览各副屏画面。
